Die Zuordnung betrifft alle Eingangseinträge, unabhängig vom Suchfilter. „Freigegeben“ ist nur eine organisatorische Kennzeichnung. Vor einem Import wird ein Sicherungsdownload ausgelöst; bitte den Download prüfen. Vorhandene IDs bleiben unverändert. Gleicher Inhalt mit anderen IDs bleibt erhalten. Löschen ist endgültig.

      ❓ Hilfe & Handy-Installation

      So speicherst du die App auf dem Handy (wie eine echte App):

      iPhone (Safari):
      1. Diese Seite in Safari öffnen
      2. Teilen-Button (Quadrat mit Pfeil) tippen
      3. „Zum Home-Bildschirm“ wählen
      4. Bestätigen → Icon erscheint auf dem Home-Screen

      Android (Chrome):
      1. Diese Seite in Chrome öffnen
      2. Menü (⋮) → „Zum Startbildschirm hinzufügen“ (falls angeboten)
      3. Bestätigen

      Die Darstellung hängt vom Browser ab. Ohne Service Worker ist kein zuverlässiger Offline-Start zugesichert.
      Funktionen im Überblick:
      • Text / Links einfügen → Inhalt wird analysiert, du wählst was gespeichert wird
      • Automatische Kategorisierung
      • Bilder & Screenshots → OCR (Text wird ausgelesen)
      • Bild aus Zwischenablage einfügen (Strg/Cmd+V)
      • Tags vergeben (kommagetrennt)
      • Kategorien mit Farben
      • 📚 Library – Gesamtübersicht aller gespeicherten Einträge (Suche, Filter, Sortierung, Statistik)
      • Suche über alles
      • Export als JSON oder Text
      • Lokale Speicherung in diesem Browser (kein geräteübergreifender Abgleich)
      • Quarantäne-Status und JSON-Sicherungsimport unter „Lokale Sammlung“
      • OCR benötigt externe Bibliothek und Sprachdateien; Bildoriginale werden nicht archiviert
      Tipp: Strg/Cmd + Enter speichert den aktuellen Text sofort.
