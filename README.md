# SammelApp

Eigenständige SammelApp für iPhone. Die Veröffentlichung der vollständigen HTML-App steht noch aus.

**Datenschutz:** Keine privaten Sammlungen, Zugangsdaten oder OAuth-Tokens in dieses öffentliche Repository hochladen.

Die Google-Drive-Anmeldung benötigt eine HTTPS-Webadresse, eine passende Google-OAuth-Web-Client-ID und die konfigurierte Google Drive API.
